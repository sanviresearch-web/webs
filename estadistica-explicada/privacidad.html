Política de privacidad

Última actualización: 26 de noviembre de 2026.

Quién usa esta aplicación

La herramienta de publicación de Estadística Explicada es una aplicación privada. Solo la usa el propietario del canal de YouTube «Estadística Explicada», con su propia cuenta de Google, para gestionar ese canal.

Qué datos usa

  • YouTube Data API: sube vídeos, miniaturas y subtítulos del propio canal, y lee la lista y los datos públicos de sus vídeos.
  • YouTube Analytics API (solo lectura): lee las estadísticas agregadas de los vídeos del propio canal (vistas, retención, fuentes de tráfico, suscriptores). No contiene datos personales de los espectadores.

Dónde se guardan

Los permisos de acceso (tokens de OAuth) y las estadísticas descargadas se guardan solo en el ordenador del propietario. No se envían a ningún servidor propio ni a terceros, no se venden y no se usan para publicidad.

Cumplimiento

El uso de los datos de las API de Google cumple la política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. Esta aplicación usa los servicios de API de YouTube; consulta también los Términos del servicio de YouTube y la Política de privacidad de Google.

Cómo retirar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.
